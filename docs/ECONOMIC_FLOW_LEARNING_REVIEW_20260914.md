# 9월 14일 경제 이해관계·이동 경로 학습 평가

사용자 목표: 경제 초보자가 글을 읽고 세계 각국의 경제 이해관계, 자원 이동, 경제흐름을 이해할 수 있다. 단순 구조 검증 통과를 내용 품질 달성으로 취급하지 않는다.

## 고정 입력과 범위

- 출발점은 [피드백 분석](ECONOMIC_FLOW_FEEDBACK_20260914.md)의 공개 DEV revision 3이다.
- 9월 14일의 실제 저장 기사 창에 미수집 캐나다–EU·AI 안전 경고 기사와 미확보 성장 전망 원문을 별도 복원했다. 브릭스는 저장 원문을 사용한다. 06:46 발행된 AI 종합판은 05시 마감 뒤이므로 9월 14일 입력에 섞지 않는다.
- 원격 DEV의 기사·관측·경제원리 세 테이블만 읽어 `economic_briefing_review_learning_20260914`에 복사했다. 사용자·인증 테이블과 공개 결과 테이블은 복사하지 않는다. 원본 DB는 변경하지 않는다.
- 덤프 원본과 로컬 PostgreSQL 14 호환 사본을 각각 보존한다. 호환 사본에서는 PostgreSQL 17의 `transaction_timeout` 설정 한 줄만 제외하며 데이터·제약은 바꾸지 않는다.
- 원문·요청 캐시·중간 결과는 git 제외 경로 `pipeline-debug/flow-learning-20260914/`에 남긴다. 캐시를 재사용해도 전체 실행의 논리적 usage를 유지해 비용 가드를 우회하지 않는다.

## 수용 기준

모든 최종 본문·Q&A를 직접 원문과 대조한다. 키워드가 있다는 이유로 내용 통과를 선언하지 않는다. 초보자 이해 수준은 실제 사용자 학습 실험을 대신할 수 없으므로, 아래 읽기 검토 기준을 충족하거나 경미한 잔여 문제만 남을 때 ‘목표에 근접’으로 평가한다.

1. 기업 제품·실적·수혜와 기관 입찰이 독립 토트를 차지하지 않는다. 국가 성장 전망, 공급망·통화·자금 흐름을 빠뜨리지 않는다.
2. 브릭스: 중국·러시아의 미국 금융 의존 축소 동기, 미국의 달러 패권 도전 경고, 인도의 현지통화 결제와 단일통화 구별을 설명한다. 경고는 2024년 발언이며 새 관세 시행으로 쓰지 않는다.
3. 캐나다: 미국과의 관세 갈등, EU 접근 목적, 전략적 공급망의 시장 접근, 제도적 부담과 국내 반발, EU의 협상 도구 의심, 대체 시장의 한계를 보존한다. 검토·전언을 합의·실행으로 바꾸지 않는다.
4. 한국 성장 전망: AI 투자→반도체 수출→성장과, 금리·부채→소비·투자 제약을 설명한다. 연구원의 전망·조건부 위험을 실제 성장 결과로 쓰지 않는다.
5. 자원·자금 이동: 공급 차질과 대체 항로, 무역의 중간 생산 거점, 외국인 채권 자금과 환헤지 비용·지수 편입 자금의 차이를 실제 근거에 맞게 설명한다. 같은 단어가 나온다는 이유로 무관한 흐름을 합치지 않는다.
6. Q&A는 필요한 뜻과 중간 과정을 설명한다. 본문의 재진술, 불필요한 기술 세부, 무관한 예시, 질문과 무관한 자료 부족 문구로 채우지 않는다.
7. 본문·Q&A 문단은 한 문장 소제목으로 핵심 관계를 먼저 보여준다. 소제목에도 원문의 주체·시점·조건이 유지된다. 기존 글도 화면에서 정상 표시된다.
8. 장기 기억은 원문으로 추적 가능하며, 검색용 text에도 핵심 상대방 입장과 조건을 남긴다. 과거 생성문을 사실 근거로 넣지 않는다.
9. 원문 문단·숫자·기사 coverage·질문별 인용 범위 검증과 일일 USD 0.14 가드를 유지한다. 단위·화면 검사와 실제 날짜 전체 실행을 구별해 기록한다.

## 회귀 검사에서 발견한 별도 문제

9월 11일은 로컬 원본의 기사 ID 체계가 원격 DEV와 달라 로컬 원본 세 테이블을 별도 평가 DB에 복사했다. 첫 준비 실행에서 V26 누락을 확인해 해당 평가 DB에만 V26을 적용했다. 두 번째 실행은 기사 1,102건 중 선별한 20건을 추출·설계한 뒤 **첫 편집 묶음에서 1,764 tokens 한도에 도달하여 JSON이 잘렸다**. 설계 실패가 아니며, 해당 실패 호출 비용은 반환된 usage_json 합계에 포함되지 않으므로 실패 실행의 표시 비용을 총 API 비용으로 쓰지 않는다.

기존 편집 배분은 흐름마다 본문을 같은 크기로 보고 질문 수에만 비례했다. 한 흐름의 근거 관측이 13개여도 본문 가중치는 2였으므로, 관계가 많은 본문이 먼저 잘릴 수 있었다. V2.6은 본문 근거 수와 질문 수로 기존 전체 12,000 tokens를 배분하고 각 호출에 한도를 알려 중복 문단을 줄인다. 입력 15,000 tokens·총 출력 12,000 tokens·USD 0.14 상한과 출처·숫자 검증은 변경하지 않는다.

## 화면·자동 검증

실제 `DailyBriefing` 컴포넌트와 생성된 결과 JSON으로 검증 화면을 띄웠다. 920px 본문 영역과 390px iframe의 휴대폰 폭에서 소제목·문단·한국어 줄바꿈을 확인했고, 본문은 h3, Q&A 소제목은 h4로 접근성 트리에 나타났다. 기존 공개 글은 소제목을 강제로 추정하지 않고 기존 문단 그대로 표시됐다. 사용자 인증이나 공개 DB 결과를 대신하는 가짜 데이터 경로를 제품 코드에 추가하지 않았다.

`check-briefing-paragraphs.mjs`는 기존 텍스트, 새 소제목, CRLF, 잘못 닫힌 표식, HTML 문자열을 검사한다. 수집 테스트는 3시간·25시간 전 RSS 기사를 회수하고 27시간 전 기사와 피드 중복을 제외한다. 기존 편집 분할 테스트는 질문 수가 같아도 근거가 많은 본문에 더 큰 출력 몫을 주는지 확인한다.

9월 11일의 첫 분량 배분 수정은 USD 0.12077660로 코드 검증을 통과했다. 그러나 읽기 검토에서 소제목이 ‘사우디 선박 제외’의 대상을 잘못 요약했고, PPI를 기업이 지불하는 원가 자체로 정의한 문장을 발견했다. 소제목의 포함·제외 대상과 환전 방향을 확인하도록 편집 지침을 보강했다. PPI는 생산자가 판매하고 받는 가격의 변화를 측정한다는 [미국 노동통계국의 정의](https://www.bls.gov/ppi/overview.htm)를 확인하고, 생산비 변화가 판매가격과 소비자가격으로 전달되는 과정과 지표 정의를 구별하도록 했다.

9월 14일 09번은 질문에 없는 월을 발행 메타데이터로 보충해 숫자 검증에서 거절됐다. 해당 질문의 근거가 ‘13일’이라고만 할 때 연도·월을 계산해 붙이지 않도록 했다. 10번의 편집 출력은 4,800 tokens에서 잘렸다. 한도를 늘리지 않고, 배정된 한도에 맞춘 **전체 한국어 분량**을 안내하고 같은 결론을 반복하는 답변 문단을 줄이도록 보강했다. 날짜·숫자 검증을 완화하거나 잘린 JSON을 성공으로 복구하지 않았다.

### 사용자 피드백에 대한 최종 판단

- 특정 기업의 제품·실적·수혜와 기관 입찰을 독립 데일리로 다루지 않는다. 기업명이 있는 기사라도 국가 성장·통상·공급망·자금 흐름을 분석한 기사면 근거로 사용할 수 있다. 아이폰·OLED, 기상청 입찰, 건설주 수혜는 최종 9월 14일 선정 기사에 없다.
- 캐나다의 미국 관세 갈등→EU 접근, 전략 공급망, 제도 비용과 국내 반발, 미국 관계자의 대체 시장 한계 지적, EU 관리의 협상 도구 의심을 함께 설명한다. 실제 EU 가입·조건 수락으로 쓰지 않는다.
- 브릭스의 현지 통화 결제와 단일 통화를 구별한다. 중국·러시아의 의존 축소 동기와 트럼프의 **2024년 12월 경고**를 함께 다룬다. 경고를 신규 관세 시행으로 쓰지 않는다.
- 현대경제연구원의 성장 진단과 AI·반도체 의존, 금리·가계부채·기업 조달비용 제약을 다룬다. 제3국 생산망과 성장 취약점을 한 흐름의 별도 문단으로 설명하되, 우회 생산망이 성장 전망을 직접 높였다는 인과는 만들지 않는다.
- 수송로 기사에서는 후티·사우디·미국의 입장, 항로 불안→공급 위험→가격의 연결을 설명한다. 금융시장에서는 외국인 원화채 매도→달러 환전과, 지수 추종 자금의 반대 수요를 구별한다.
- AI는 직접적인 가격·실적 수치가 없어도 규제·국가 경쟁·협력의 제약이 있으면 포함한다. 9월 13일의 안전 경고 기사만으로 미중의 정책 입장까지 추론하지 않는다. 그 관계를 실제로 보도한 9월 14일 06:46 종합판은 다음 일일 창의 사례로 통과했고, 미국 내부 규제 갈등·중국과의 경쟁·약속 검증의 어려움·조약 제안과 합의를 구별했다.

### 원문 기억 확인

최종 격리 평가 DB에서는 브릭스 6개, 캐나다 4개, 한국 성장 진단 4개의 관측이 모두 `memory_eligible=true`이고 임베딩과 직접 원문 문단을 가진다. `final-relations-memory.json`에 저장 상태를 남겼다. 트럼프 경고의 날짜와 조건, 중국·러시아의 미국 금융 의존 축소 이유, 캐나다 관세 갈등과 EU 접근 목적, 제도 비용, 미국 관계자·EU 관리의 입장을 검색용 text에서 확인했다. 기존 공개 DB에 없던 캐나다 기사를 실제 운영 DB에 자동 복원했다고 주장하지 않는다.

### 자동 결과와 교정본의 구분

최종 독자용 파일은 `pipeline-debug/flow-learning-20260914/12-source-reviewed/reader.md`와 `result.json`이다. 11번 자동 결과는 그대로 보존했다. 원문 대조에서 외국어 한 단어, 기존 대출의 이자 조건, 미국 관계자의 발언 주체, 브릭스 공동선언과 인도 발언의 구분 등을 포함해 **9개 본문·답변 필드**를 교정했다. 불필요한 군사·피난민 세부를 줄이고 선물의 뜻을 보완했으며, 달러 신뢰 저하의 배경도 본문에서 읽을 수 있게 했다.

`editorialReview`에 원본 해시·수정 전후·이유를 기록했다. 흐름·질문의 ID와 순서, 기사·원리·인용 범위, 원래 trace는 바꾸지 않았고, 수정한 각 필드의 수치 집합에 새 숫자가 없음을 확인했다. 기존 숫자·범위 검증의 조건을 유지하면서 표현과 의미를 사람이 대조한 결과이며, 별도 자동 의미 검증을 통과한 것으로 표현하지 않는다. 과거 생성문을 기억 근거로 저장하지 않았다.

9월 11일 회귀에서는 PPI의 판매자 가격 정의, 발표 전후 순서, 국채 조기매입의 기대 차이, 선박 제한의 포함·제외 대상, 국가별 선택과 비용을 확인했다. 9월 12일에는 미중 투자 목록 대 건별 심사, 제재와 자금 이동, 러시아산 가스 의존과 미래 금수, 환율 양방향 압력·초장기물 예외를 확인했다. **남은 한계:** 9월 12일 연료 대체 답변에는 석탄용 설비 조건이 있지만 본문은 원문의 가스 설비 표현을 압축해 적어, 본문만 읽을 때 필요한 설비 조건이 충분히 드러나지 않는다. 이런 세부 조건 누락과 간헐적인 어색한 표현은 여전히 독자용 편집에서 확인해야 한다. 이를 완전 자동화 완료라고 부르지 않는다.
