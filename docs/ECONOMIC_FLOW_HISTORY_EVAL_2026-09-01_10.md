## 2. 테스트에서 드러난 구조 문제와 수정

### 전체 제목·요약을 한 번에 넣으면 너무 비싸다

9월 1일 1,008건을 한 번에 보낸 최초 Luna 선별은 입력 155,799토큰을 사용했다. 한국어 RSS 요약 1,000개는 문자 수보다 토큰 수가 훨씬 컸다.

최종안은 다음 두 호출로 바꿨다.

1. 제목만 시간대별 라운드로빈 순서로 보내 최대 80개 ID를 넉넉히 남긴다.
2. 그 80개에만 RSS 요약을 붙여 최대 20개 원문 확인 대상을 고른다.

9월 1일 입력은 155,799토큰에서 46,612토큰으로 70.1% 줄었고, 선별 비용은 약 $0.0327에서 $0.0118로 64% 줄었다. 시간순으로만 입력했을 때 생긴 새벽 기사 편향도 시간대 라운드로빈으로 제거했다.

### 원문 추출을 묶으면 실패 비용이 커진다

기사 4개씩 묶은 Luna 관측 추출은 두 번째 묶음이 240초에 시간초과됐다. 앞 묶음의 결과와 usage도 최종 파일에 기록되지 않았다.

최종안은 기사당 한 요청, 완료 즉시 체크포인트 저장으로 바꿨다. 호출 수는 늘지만 한 기사 실패가 다른 기사 결과를 없애거나 재호출하게 만들지 않는다. 198건 실행은 모두 완료됐다.

### 숫자 검사는 출력 규칙과 맞아야 한다

Luna가 본문의 `지난달 31일`을 `8월 31일`로 계산해 쓰자 의미가 맞아도 숫자 문자열 검사가 문장 전체를 버렸다. 숫자 파서를 복잡하게 만들지 않고, Luna가 날짜·수치·단위를 계산하거나 바꾸지 않고 본문 표현 그대로 쓰게 수정했다. 유효 관측은 기사당 최소 하나 이상 남았고, 원문에 없는 절대 날짜를 계속 덧붙인 35개 항목은 보수적으로 폐기했다.

### 검색 원리는 전체 후보를 다시 정렬해야 한다

각 현재 연결의 원리 Top-2를 관계 순서대로 먼저 채우면 약한 원리가 뒤의 좋은 원리를 밀어냈다. 모든 원리 후보를 모은 뒤 cosine 순으로 다시 정렬하고, 0.42 이상·최대 4개·총 4,000자 규칙을 적용했다.

### 과거 후보가 어떤 현재 관측과 연결됐는지 알려줘야 한다

처음에는 history 12개만 나열해 9일 중 하루에서만 사용됐다. history 행에 검색을 일으킨 현재 C 별칭을 함께 넣되 인과 증거가 아니라고 명시했다. 수정 후 Terra는 관련 과거가 있는 9월 2·4·5·8·9·10일에만 이전 값이나 방향을 사용했고, 3·6·7일에는 억지로 쓰지 않았다.

## 3. A/B 결과

비교 조건은 다음과 같다.

```text
A: 현재 관측 + 현재 연결 + 경제원리
B: A + 이전 날짜의 원문 근거 관측
```

대표 3일에서 B는 하루 약 837~910 입력토큰을 추가했다.

| 날짜 | A | B가 추가한 변화 설명 |
|---|---|---|
| 09-02 | 당일 유가 급등 설명 | WTI 85.76달러 → 90.22달러 |
| 09-09 | 당일 브렌트유 100달러 근접 | 94.65달러 → 99.46달러 |
| 09-10 | 당일 유가·채권금리 상승 | 브렌트유 94.65달러 → 101.21달러, 미 10년물 4.821% → 4.836% |

과거 관측을 오늘 사건의 원인으로 바꾼 사례는 없었다. 관련이 없는 날에는 현재 핵심 흐름이 그대로 유지됐다. 따라서 과거 관측은 모든 흐름에 강제하지 않고 검색된 후보 중 Terra가 실제 비교에 쓸 때만 채택한다.

총 API 토큰은 844,996개다. 토큰 수는 예상보다 컸지만, 75%가 저가 Luna 입력 또는 임베딩이어서 비용은 10일 $0.6792, 하루 평균 $0.0679, 같은 밀도라면 30일 약 $2.04다. 비용의 약 70%는 Terra 최종 작성이다.

이번 설계를 찾기 위한 폐기 실험과 A/B 재호출까지 포함해 응답 usage로 확인되는 성공 호출 비용은 약 $1.3376다. 4기사 묶음 추출의 완료 후 시간초과 요청은 응답 usage를 받지 못해 이 금액에 포함하지 못했다. 따라서 이 테스트만으로 $6가 모두 소진되지는 않는다. 대시보드와 차이가 크면 같은 API 프로젝트의 다른 호출 또는 usage 미수신 요청을 별도로 확인해야 한다.

## 5. Terra reasoning 설정

9월 10일 `low`는 `medium`보다 출력이 3,630→2,644토큰으로 줄면서 품질을 유지했다. 그러나 9월 9일 `low`는 이란 제재, 중국 물가, 일본 자금흐름을 빼고 포스코 부분파업을 독립 흐름으로 올렸다. 날짜별 품질이 안정적이지 않아 운영 기본값은 `medium`을 유지한다. 동적 모델 라우터는 추가하지 않는다.

## 6. 최종 판단
