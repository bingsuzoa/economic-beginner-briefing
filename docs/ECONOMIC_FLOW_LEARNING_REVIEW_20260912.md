## 평가 자료와 방법

원래 날짜 창과 사전 후보를 고정하고, 사용자가 준 여섯 URL의 본문·발행시각·HTML을 한 번 저장했다. 기존 네 기사의 최신 판본과 누락된 두 기사를 포함한다. 이는 여섯 기사 복원이며 누락된 밤 전체의 완전한 복원이 아니다.

`DailyLearningReplayTest`는 이름이 `economic_briefing_review_...`인 명시적 평가 DB에서만 실행한다. 기사·관측·경제원리만 복사하고 사용자·인증 테이블은 복사하지 않는다. 서비스의 선별·추출·설계·검색·편집·예산·근거 검증 코드를 그대로 호출한다. 동일 요청은 저장된 응답을 재사용하지만 운영 비용 검사에는 원래 usage를 돌려주어 예산 검사를 우회하지 않는다. 새 요청 실제 추정 비용은 별도로 기록한다. 모델을 추가하거나 검증 LLM을 호출하지 않는다.

단계별 비교와 전체 경로 재현을 구별한다. 후보 고정 평가는 제목 사전선별을 평가한 결과가 아니다. 최종 전체 실행은 제목 사전선별부터 다시 확인한다. 원문·응답·중간 결과는 저작권 자료와 실행 자료이므로 git 제외된 `pipeline-debug/flow-learning-20260912/`에 둔다.
