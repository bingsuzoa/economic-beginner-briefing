# 2026-09-09 경제흐름 실데이터 반복 테스트

## 결론

최종 구조는 테스트 기준을 통과했다.

- `중동 긴장 → 유가 → 물가 경계 → 채권금리`를 여러 기사와 과거 관측으로 연결했다.
- `AI 인프라 투자 → 대만 수출 → SSD 공급 제약 → 대체재 HDD 가격`을 놓치지 않았다.
- 의미가 약한 세 번째 흐름을 숫자 맞추기로 만들지 않고 2개에서 멈췄다.
- 기사·문단·관측·원리 ID와 숫자 검사는 모두 통과했다.
- 최종 운영 경로의 추정 비용은 하루 약 **$0.055**, 30일 약 **$1.65**다.

첫 실행은 실패했고 모델 등급이나 지시문을 부분 수정하는 것만으로는 해결되지 않았다. 선별 이유를 다음 추출 단계의 관측 후보로 재사용하고, 원문 추출을 기사별로 격리하며, 현재 관측끼리의 연결 후보를 같은 임베딩으로 만드는 구조로 바꾼 뒤 통과했다.

## 반복 과정과 구조적 진단

### 1차: 대형 배치 추출 — 실패

637건에서 12개 기사를 선별하고 27개 관측을 만들었지만 다음 문제가 있었다.

- 유가 기사에서 실제 가격을 빼고 공급 우려만 추출했다.
- `AI 수요 → 대만 수출`과 `SSD 부족 → HDD 가격` 관측은 있었지만 Terra가 하나로 묶지 않았다.
- 고용과 가계대출 같은 단일 기사 해설을 우선했다.

문단 ID와 숫자 검증은 누락을 찾지 못한다. 존재하지 않는 근거는 막을 수 있지만 중요한 근거를 뽑지 않은 것은 코드가 알 수 없기 때문이다.

### 2차: 모델·reasoning·verbosity 조정 — 실패

추출 배치를 줄이고 Luna reasoning을 높이거나 Terra를 추출에 사용해도 핵심 관측이 번갈아 누락됐다. 이는 모델 가격이나 단순 프롬프트 강도의 문제가 아니었다.

### 3차: 선별과 추출의 계약 변경 — 통과

선별 단계의 `reason`을 진단 문자열로 버리지 않고 다음 단계의 `selectionHint`로 사용했다. 단, 근거로 취급하지 않고 원문에서 확인·정정하게 했다.

관측 추출은 선택 기사 전체를 한 요청에 넣지 않고 기사별로 실행했다.

```text
선별 reason: AI 수요로 대만 수출이 41% 증가
→ Luna가 해당 기사 원문에서 정확한 주체·값·문단을 확인
→ 첫 관측으로 확정
→ 명시 원인·제약·전망을 최대 2개 추가
```

이 변경으로 다음 핵심이 모두 보존됐다.

- 중국 생산자물가 3.8%, 소비자물가 0.8%, 에너지 가격 원인
- 전체 취업자 증가와 청년 취업자 46개월 감소
- 대만 수출 41%와 대만 재정부의 AI 인프라 설명
- SSD 공급 제약, HDD 6분기 연속 상승, 제품별 15%·10% 상승
- 3년물 국고채 3.910%와 유가·미국 CPI 경계

기사별 호출은 프롬프트를 조금 반복하지만 한 기사 실패만 재시도할 수 있고, 여러 원문을 한꺼번에 처리할 때 생긴 주의력 경쟁을 제거했다.

### 4차: 현재 관측 연결 후보 추가 — 통과

관측 임베딩을 과거 검색에만 쓰지 않고 서로 다른 기사 관측 사이의 cosine도 계산했다. 기사 쌍마다 가장 유사한 관측 한 쌍만 남겨 상위 15쌍을 Terra에 `relatedCurrent` 후보로 보냈다.

이 값은 근거나 인과 판정이 아니다. Terra가 전체 53개 관측에서 연결 가능성이 높은 쌍을 먼저 보게 하는 색인일 뿐이다. 추가 임베딩 호출과 추가 LLM은 없다.

### 5차: 과거 관측 사용 — 한 번 더 수정 후 통과

로컬 DB의 9월 3일 실제 채권 기사에서 다음 관측을 만들었다.

```text
H01  3일 국고채 3년물 금리는 4.2bp 내린 연 3.888%에 마감했다.
H02  외국인 국채선물 순매수, 주요국 장기금리 하락, 원화 강세가 하락에 영향을 줬다.
```

H01은 9월 9일 3년물 3.910% 상승 관측과 cosine 0.738로 가장 높게 검색됐다. 첫 Terra 실행은 H01 ID만 반환하고 실제 설명에는 비교를 쓰지 않았다. 검색 문제가 아니라 편집 프롬프트 문제였으므로 다음 한 줄을 추가했다.

```text
history ID를 반환할 때는 과거 날짜와 방향 또는 값을 비교 문장에 실제로 쓴다.
```

재실행에서는 `9일 3.910%`와 `3일 3.888%`를 본문에서 직접 비교했다.

### 6차: 선별 최대 12개 — 실패, 최대 20개 후보 — 통과

운영 Schema를 최대 12개로 줄여 똑같이 재실행하자 채권금리 기사를 놓치고 포스코 파업·은행 상품금리·애프터마켓을 넣었다. Luna의 순위를 곧바로 정답으로 취급한 것이 문제였다.

선별은 최대 20개의 고재현율 후보를 반환하게 하고, 중복을 제거한 19개를 기사별로 추출했다. Terra 입력은 53개 관측을 넣고도 7,930토큰으로 15,000 상한 안에 들었다. 최종 결과는 파업·은행 상품·애프터마켓·지역 투자협약을 모두 버리고 채권금리와 AI 흐름을 유지했다.

### 2. AI 인프라 투자가 수출·반도체·저장장치 가격을 함께 끌어올리는 흐름

- 현재 관측: 대만 수출 3개, 저장장치 3개, 파운드리 2개

## 경제원리 DB 판정

DB에는 수요·공급, 중동 유가, 유가와 물가에 관한 청크가 존재한다. 그러나 AI 저장장치 관측의 dense vector 상위 후보에는 재고·경기둔화 같은 낮은 관련도의 청크도 섞였다.

원리 사용을 강제하지 않았기 때문에 Terra는 이들을 최종 근거로 쓰지 않았다. 이것이 정상이다. 현재 기사들이 `수요 급증 → 공급 제약 → 대체재 가격 상승`을 이미 직접 설명하는데 일반 원리를 반복하면 정보가 늘지 않는다.

따라서 경제원리 검색은 다음처럼 제한한다.

- 현재 기사 쌍의 평균 임베딩으로 상위 2개 조회
- 초기 cosine 하한 0.42 미만 제외
- Terra가 설명에 실제 작동 원리를 추가한 경우만 원리 ID 반환
- 원리 후보가 없거나 중복이면 빈 배열 허용

원리 DB를 반드시 쓰는 것이 성공 조건은 아니다. 기사 근거만으로 설명할 수 없는 연결 과정을 정확히 보강할 때만 쓴다.

30일 단순 환산은 약 **$1.65**다. 12개로 줄였을 때의 누락 위험보다 19개를 처리하는 추가 비용이 하루 약 0.8센트로 작아 고재현율 경로를 택했다.

이 표는 최종 운영 경로를 한 번 실행한 비용이다. 실패 원인을 찾기 위해 수행한 모델·배치·프롬프트 비교 호출은 포함하지 않으므로 이번 테스트 세션의 실제 차감액은 더 크다.

모든 호출은 `prompt_cache_options.mode=explicit`이고 cache breakpoint를 두지 않았다. 실행마다 달라지는 기사 원문을 자동 cache write해 1.25배 비용을 내지 않기 위해서다. 실제 사용량은 cache write 0, cache hit 0이었다.

### 기존 설계 기준선 — 실패

기존 선별 프롬프트는 숫자로 확인되는 경제변화를 중심으로 8건을 골랐다. 유가·가스·미 국채·주택대출·핀란드 투자·K-뷰티·아르헨티나 소비는 골랐지만, 유조선 피격과 한-EU 산업가속화법을 버렸다. Terra 결과는 5개였고 `중국어 사기 플랫폼의 가상화폐 동결`까지 독립 경제흐름으로 게재했다.

최종 문장 프롬프트만 고쳐서는 앞에서 버린 국가 관계와 상류 원인을 복구할 수 없었다. 원인은 관측의 정의가 가격·수치에 치우친 것이었다.

### 구조 수정

1. 연합뉴스 URL의 `AKR + 날짜 + 원기사 번호`가 같으면 최신 발행판 하나만 Luna에 보낸다. 39건이 36건으로 줄었고 짧은 초판 대신 종합판이 남았다.
2. Luna 선별은 경제변수뿐 아니라 그 변수의 상류 원인·제약과 같은 입력 안에서 연결되는 국가·주체의 이해관계도 원문 확인 후보로 고른다.
3. 선별 `reasoning=none`은 동일 입력 재실행에서 IAEA 맥락 기사를 놓쳤다. 하루 한 번인 선별만 `low`로 올리자 핵심 원인 기사를 회수했으며 추가 reasoning은 333토큰이었다.
4. 기사별 관측 추출은 `reasoning=none`으로도 근거 ID와 발화 강도를 보존했다. 관측 세 자리는 `핵심 변화 → 기사 명시 원인 → 국가·주체 관계` 순으로 배분한다.
5. 수치는 원문 표기 그대로 복사한다. `3천500만`을 `3,500만`으로 바꾼 표현이 보수적 문자열 검사에서 탈락하는 문제를 별도 의미 검증 LLM 없이 막았다.
6. 과거 검색은 같은 과거 기사에서 가장 가까운 관측 하나만 남겨 같은 유가 기사의 유사 관측이 4개 들어오던 것을 2개 기사·2개 관측으로 줄였다.
7. `relatedCurrent` 상위 15쌍은 낮은 유사도도 탐색 단서로 유지한다. 경제원리에만 cosine 0.42 하한을 적용하고 최대 4개·4,000자로 제한한다. 연결 탐색 하한과 원리 품질 하한을 같은 값으로 쓰지 않는다.
8. 최종 흐름 수는 고정하지 않는다. Terra가 근거 있는 독립 흐름을 모두 반환하고 전체 출력 예산과 흐름당 문장 수로 토큰을 통제한다.

### 최종 결과

최종 Terra는 사람 기준의 여섯 핵심 흐름을 모두 만들었다. 후보로 들어간 가상화폐 단속과 아이폰 제품 발표는 최종에서 제외했다. 중동 흐름에서는 IAEA 관측을 직접 사용하지 않았지만, 미·이란 보복 공격, 호르무즈 통제 경고, 이라크 유조선 피격, 유럽의 러시아·카타르 가스 노출을 사용해 국가 관계와 경제 경로를 설명했다. IAEA 관측은 경제적 연결을 억지로 붙이지 않고 미사용한 것으로 판정한다.
